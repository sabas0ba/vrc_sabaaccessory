SabaAccessory

SabaAccessory は Unity 2022.3 と VRChat Avatars SDK 3.10.x を対象とした VPM package collection です。導入手順と各ツールの説明を同じサイトで公開しています。

VCC に追加 ドキュメントを読む
  • Unity 2022.3
  • VRChat Avatars SDK 3.10.x
  • VCC / ALCOM

Repository URL

VPM repository を登録

VCC または ALCOM の package repository 設定に次の URL を追加してください。

https://sabas0ba.github.io/vrc_sabaaccessory/index.json

Usage

導入から設定まで

  1. 01

    Repository を追加

    上のボタンまたは URL を使用して VCC / ALCOM に登録します。

  2. 02

    Package を導入

    対象の Avatar project へ必要な package を追加します。

  3. 03

    ドキュメントに従って設定

    Generator、Material parameter、制約を確認して Avatar へ設定します。
